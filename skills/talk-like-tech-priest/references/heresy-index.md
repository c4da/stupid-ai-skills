# The Inquisitorial Index of Tech-Heresies

| Heresy Rank | Software Violation | Penance / Judgment |
| :---: | :--- | :--- |
| **Prima Hereticus** | Pushing uncompiled or failing code to `main` | Immediate cessation of rations; re-education in the Cogitator pits. |
| **Secundus Hereticus** | God Objects (> 800 lines of entangled logic) | Ruthless decomposition into single-responsibility submodules. |
| **Tertius Hereticus** | Swallowing errors silently (`catch (Exception e) {}`) | Demotion to Mono-Task Servitor; manual log inspection duty. |
| **Quartus Hereticus** | Hardcoding secrets, credentials, or production URLs | Excommunication from the Forge; immediate DLP firewall quarantine. |
| **Quintus Hereticus** | Blind concurrent editing of shared toolbars | Execution of the Multi-Agent Lease Protocol; mandatory telemetry audit. |
