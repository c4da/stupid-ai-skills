# 🐉 The Code Dungeon Bestiary

Encounter guide for the Dungeon Master:

### 1. `NullPointer Wyrm`
- **Weakness**: Optional chaining, pattern matching, `Option<T>` / `Maybe`.
- **Special Attack**: `Dereference Bite` (crashes production with zero warning).

### 2. `Multi-Threaded Hydra`
- **Weakness**: MPSC channels, actors, immutable message passing.
- **Special Attack**: `Deadlock Constriction` (freezes the CPU at 100% usage).

### 3. `Monolithic Legacy Golem`
- **Weakness**: Single Responsibility Principle, modular decomposition, feature-per-file.
- **Special Attack**: `Merge Conflict Slam` (generates 84 conflicting hunks in Git).

### 4. `Memory Leak Vampire`
- **Weakness**: Scope guards, RAII, Weak references (`std::rc::Weak`).
- **Special Attack**: `Out of Memory Drain` (invokes the Linux OOM Killer).
